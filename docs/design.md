# photo-katsudou 設計メモ

ブラウザ（PWA）で動くフレームカメラアプリ。ユーザーが登録した画像素材を
カメラ映像に重ねて撮影する。

## 決定事項

| 項目                     | 決定                                                                                                                                                                                                                                                                                                                                                              |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| フレーム比率とカメラ映像 | フレームごとに比率を固定し、カメラ映像は **cover で切り抜く**（歪ませない）                                                                                                                                                                                                                                                                                       |
| 座標系                   | フレーム内の位置・サイズは **割合（0〜1）** で保持                                                                                                                                                                                                                                                                                                                |
| 撮影履歴                 | 持たない。保存・共有後は端末の画像ライブラリに任せる                                                                                                                                                                                                                                                                                                              |
| 技術                     | フレームワークを使う（下記「技術構成」）                                                                                                                                                                                                                                                                                                                          |
| 向き                     | 縦長フレーム・横長フレームの両方に対応。端末の縦持ち・横持ちの両方に対応                                                                                                                                                                                                                                                                                          |
| 素材の透過部分           | 透過部分にはそのままカメラ映像が映る。素材の形に特化した処理（外枠の塗りつぶし等）は入れない。不要部分は利用者が端末の写真アプリでトリミングする                                                                                                                                                                                                                  |
| 公開                     | 開発版（`APP_CHANNEL=dev`）はこのリポジトリの GitHub Pages に Actions でデプロイして動作確認に使う。一般公開版（`APP_CHANNEL=prod`）は `v*` タグの push で別アカウントのリポジトリの GitHub Pages 用ブランチに push する（Deploy key で認証）。どのパスに置かれても動くよう相対パスでビルドする。両者はアプリ名と manifest の `id` を変えてホーム画面上で区別する |

## 画面遷移

```
ホーム ─┬─ フレーム一覧 ─── フレーム編集 ──(シート)── 素材ライブラリ
        │                      └─ 新規作成ダイアログ（比率選択）
        ├─ カメラ撮影 ──(シャッター)── プレビュー ─┬─ 保存（共有シート / ダウンロード）
        │     └─(シート)── フレーム選択            ├─ 共有
        │                                          └─ キャンセル → カメラ撮影
        ├─ 設定
        └─ 使い方 / ホーム画面追加ガイド
```

- ブラウザタブで開かれた場合（`display-mode: standalone` でない場合）はホームに
  「ホーム画面に追加」バナーを出し、ガイド画面へ誘導する。
- カメラ権限拒否・非 HTTPS・非対応ブラウザはカメラ撮影画面内のエラー表示で扱う。

## データモデル（IndexedDB）

```ts
// 画像素材
interface Asset {
  id: string;
  name: string;
  blob: Blob; // 取り込み時に長辺 4096px 上限へ縮小。PNG/WebP は透過保持
  mimeType: string;
  width: number; // px（縮小後）
  height: number;
  thumbnail: Blob; // 一覧表示用
  createdAt: number;
}

// フレーム
interface Frame {
  id: string;
  name: string;
  aspect: { w: number; h: number }; // 例: {w: 3, h: 4} / 素材由来なら {w: 811, h: 1182}
  layers: Layer[]; // 配列の先頭が最背面
  thumbnail: Blob;
  createdAt: number;
  updatedAt: number;
}

// レイヤー（座標はすべてフレームに対する割合）
interface Layer {
  id: string;
  assetId: string;
  cx: number; // 中心 X（フレーム幅に対する割合）
  cy: number; // 中心 Y（フレーム高さに対する割合）
  width: number; // 幅（フレーム幅に対する割合）。高さは素材の縦横比から導出
  rotation: number; // 度
  opacity: number; // 0〜1
  flipX: boolean;
  flipY: boolean;
  visible: boolean;
  locked: boolean;
}
```

- レイヤーの高さを保持せず素材の縦横比から導出することで、比率の異なる端末で
  表示しても素材が歪まない。
- 縦横の向きは `aspect` から導出する（`w < h` なら縦長）。別フィールドは持たない。

## フレーム比率

新規作成時に選ぶ。

- **素材に合わせる**: 選んだ素材の縦横比をそのままフレーム比率にし、その素材を
  全面（`cx=0.5, cy=0.5, width=1`）に配置する。添付サンプルのような
  「完成済みフレーム画像」を 1 枚使うケースはこれで一発で済む。
- **プリセット**: 3:4 / 2:3 / 9:16 / 1:1 など。縦横入れ替えトグル付き。
- 作成後の比率変更は可能とするが、レイヤーは割合座標のためそのまま再配置される
  （素材自体は歪まない）。

## 描画の共通ロジック

編集画面・カメラプレビュー・撮影時の合成は、同じ関数でレイアウトを計算する。

```
layout(frame, outputWidth, outputHeight) -> 各レイヤーの px 座標・サイズ・回転
coverCrop(videoW, videoH, frameAspect)   -> カメラ映像の切り抜き矩形
```

表示用（画面サイズ）と出力用（高解像度）で解像度だけが違うため、プレビューと
保存画像で位置がずれない。

## 画面ごとのレイアウト

- 画面の空き領域にフレームを **contain** で最大表示し、余白は暗色で埋める。
- 操作ボタンは縦持ちなら下部、横持ちなら右側（利き手設定で左右反転は任意）。
- 縦長フレームを横持ちで使う等、向きが合わない場合は小さく表示されるので
  「端末を回転すると大きく表示されます」のヒントを出す。
- `manifest` の `orientation` は `any`。`safe-area-inset` を考慮する。

## カメラ撮影

- `getUserMedia` は高めの解像度を `ideal` で要求し、実際の `videoWidth/Height` を
  使って cover 切り抜きを計算する（端末の向きで映像が縦横入れ替わっても同じ式で扱える）。
- `enumerateDevices` で全カメラを列挙し選択可能にする。前面/背面の簡易トグルも置く。
- 前面カメラは画面表示を鏡像にし、保存画像の鏡像/非鏡像は設定で選ぶ。
- 出力解像度: カメラ映像の切り抜き領域の解像度を基準とし、長辺 4096px を上限とする。
- シャッター → canvas で合成（`src/lib/render.ts` の `composePhoto`）→ Blob → プレビュー。
- 撮影中は Screen Wake Lock で画面消灯を防ぐ。

## 保存・共有

- `navigator.canShare({ files })` が真なら Web Share API で共有シートを開く
  （iOS ではここから「画像を保存」でカメラロールに入る）。
- 共有できない環境では `<a download>` でダウンロードする。
- 形式は JPEG（品質 0.92 既定）/ PNG を設定で選ぶ。ファイル名は
  `photo-katsudou_<フレーム名>_<yyyyMMdd-HHmmss>.jpg`。

## フレーム編集

- 選択レイヤーに拡大縮小・回転ハンドル（アスペクト比固定）、ドラッグで移動。
- レイヤーパネル: 並べ替え、表示/非表示、ロック、複製、削除、不透明度、反転。
- ロックされたレイヤーはヒットテストから除外し、下のレイヤーを掴めるようにする。
- 全体の「固定 / 編集」モード切替。固定中はすべてのレイヤーが操作不可。
- Undo / Redo、中央・端へのスナップ、「全面に合わせる」ボタン。
- 背景にカメラ映像を表示して確認できるトグル（既定はチェッカー柄）。
- 変更は自動保存（デバウンス）。

## 技術構成

| 用途           | 採用                                                                                            |
| -------------- | ----------------------------------------------------------------------------------------------- |
| ビルド         | Vite                                                                                            |
| UI             | React + TypeScript                                                                              |
| ルーティング   | React Router（HashRouter。静的ホスティングでそのまま動く）                                      |
| 編集キャンバス | react-konva（Transformer で拡大縮小・回転ハンドル）                                             |
| IndexedDB      | Dexie                                                                                           |
| 状態管理       | Zustand                                                                                         |
| PWA            | vite-plugin-pwa（manifest / Service Worker / 更新通知）                                         |
| テスト         | Vitest（レイアウト計算などの純粋関数）                                                          |
| 品質           | ESLint + Prettier                                                                               |
| ホスティング   | GitHub Pages（HTTPS 必須のため）。`vite` の `base: './'` と HashRouter で配置先パスに依存しない |

## データ保護

- 起動時に `navigator.storage.persist()` を要求する。
- iOS ではホーム画面版と Safari で IndexedDB が別になる旨をガイドに記載する。
- （未実装）フレーム + 素材を 1 ファイル（zip）でエクスポート / インポートできるようにする。
